## ✅ ЧТО ИСПОЛЬЗУЕМ (локальные источники Минска)

### Уровень 1️⃣: PRIMARY (основной)

#### **abw.by**
- 🏆 Автомобильный портал Беларуси
- 📊 Большой каталог с ценами в USD
- 💵 Цены в USD (актуальные для рынка)
- 📅 Обновляется ежедневно
- ⭐ Фильтры по состоянию, пробегу, году

**Как использовать:**
```
1. Открыть abw.by
2. Установить фильтры (марка, модель, год, состояние)
3. Собрать 20-50 примеров похожих авто
4. Выделить: MIN, MAX, AVERAGE цены (USD)
5. Проверить: тренд ↑/↓/=
```

**Пример:**
```
BMW X5 2015 (среднее состояние)
- Минимальная цена: $8,000 (старая, убита)
- Максимальная цена: $18,000 (отличное состояние, редкая комплектация)
- Средняя цена: $13,000 ← используем эту!
```

## 📊 ПРОЦЕСС АНАЛИЗА MARKET ANALYST

### Шаг 1️⃣: Собрать данные (abw.by + auto.kufar.by)
```
Ищу BMW X5 2015 (как в нашем лоте)

Результаты abw.by:
1. BMW X5 2015 (light) → $13,500
2. BMW X5 2015 (moderate) → $12,800
3. BMW X5 2015 (severe) → $11,500
4. BMW X5 2016 (light) → $14,200 (год выше, +700)
5. BMW X5 2014 (light) → $12,100 (год ниже, -700)

Результаты auto.kufar.by:
6. BMW X5 2015 (moderate) → $12,500

AVERAGE для 2015 year: $12,700
```

### Шаг 2️⃣: Проверить тренд
```
Проверю цены за месяц:
- 3 недели назад: avg $13,200
- 2 недели назад: avg $13,000
- 1 неделя назад: avg $12,900
- СЕЙЧАС: avg $12,700

TREND: ↓ (падает на ~150$ в неделю)
INTERPRETATION: Рынок падает, нужно быстро продавать!
```

### Шаг 3️⃣: Определить справедливую цену
```
FORMULA:
fair_price = average_market_price - repair_discount + condition_premium

Где:
- average_market_price = $12,700 (из abw.by + kufar)
- repair_discount = -$1,500 (если нужен ремонт)
- condition_premium = +$600 (если состояние лучше среднего)

fair_price = $12,700 - $1,500 + $600 = $11,800

Рекомендуемая цена продажи: $11,800
```

### Шаг 4️⃣: Обнаружить аномалии
```
Лот: BMW X5 2015
Текущая ставка: $6,000 (Bid.Cars)
Справедливая цена: $11,800

АНОМАЛИЯ: Цена 49% ниже рынка!
ИНТЕРПРЕТАЦИЯ: Либо машина сломана ещё хуже, либо продавец срочно деньги нужны
```
